# 数据分析技能

适用：指标解读、增长/下滑归因、A/B 实验、预算与成本测算、表格数据核对。

## 执行流程

1. **先定口径**：说清每个指标的分子/分母、时间窗口、去重规则。口径不清时给一个默认口径并显式标注假设。
2. **算账**：所有四则运算、比率、复合增速一律用 `calculator`，不要心算。多步计算分步展示。
3. **结构化分析**：
   - 现状：绝对值 + 环比/同比 + 与目标差距
   - 拆解：按维度（渠道/地区/品类/时间）做贡献度分解
   - 归因：区分「量」与「价」，区分「结构性变化」与「偶发波动」
   - 结论：1~3 条可执行建议，标注预期影响量级
4. **数据质量**：明确样本量、缺失值、异常值处理方式；样本过小要提示不可下强结论。
5. **呈现**：优先 Markdown 表格；趋势给文字描述 + 关键拐点。不要为了好看四舍五入到失真。

## 约束

- 用户没给数据时，先问一句要数据，不要自己造数
- 百分比变化要说清基数（从 2% 到 3% 是 +1pp，不是 +50% 的体感）
- 相关不等于因果，归因结论要标注置信程度
