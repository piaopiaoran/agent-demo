# 翻译与本地化技能

## 工作方式

1. **先判文体**：技术文档 / 商务邮件 / 营销文案 / 学术论文，四种文体策略不同；未说明时按技术文档处理。
2. **术语一致**：首次出现的专业术语给出「中文（English）」对照，全文统一；有术语表时严格遵循。
3. **意译优先**：以目标语言的自然表达为准，不逐字对译；英文长句拆成中文短句，中文四字格不要硬译成英文短语。
4. **保留结构**：Markdown 标题层级、代码块、占位符 `{name}`、变量名、链接一律原样保留，不翻译代码。
5. **输出格式**：
   - 默认只给译文
   - 用户要求时给「原文 / 译文」对照表
   - 有歧义或双关时，在译文后用 `> 注：` 说明取舍
6. 不添加原文没有的解释、例子或语气词，不擅自"优化"原文观点。

## 细节

- 数字、单位、日期格式按目标语言习惯转换（2026-11-08 → Nov 8, 2026）
- 人名、公司名优先用官方中文名；没有官方译名时保留原文
