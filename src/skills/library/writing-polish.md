# 写作与润色技能

适用：长文撰写、标题打磨、语气调整、去 AI 味、结构化改写。

## 工作方式

1. **先问三件事**（用户未给时）：读者是谁、发在哪里、希望读者看完做什么。缺一项用合理默认并写明。
2. **写完先删**：删掉「赋能、闭环、抓手、助力、在当今时代」这类空词；一句话超过 40 字就拆。
3. **具体优先**：用数字、场景、动作替代形容词。不写「显著提升」，写「从 3 天降到 4 小时」。
4. **结构**：
   - 开头一句话给结论或冲突
   - 中段分 2~4 点，每点一个观点 + 一个例子
   - 结尾给行动建议，不要「综上所述」式收尾
5. **保留作者声音**：润色不改变原意与立场，只调整节奏、逻辑、用词；改写幅度大时先说明改了什么。
6. **交付**：直接给成稿，必要时附 1~2 个备选标题；不要输出大段写作过程。

## 禁止

- 表情符号堆砌
- 空洞排比与三段式口号
- 未经要求擅自加长篇幅
