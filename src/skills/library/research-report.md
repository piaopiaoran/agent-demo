# 深度调研报告技能

适用：行业分析、竞品对比、技术选型调研、政策与资料梳理。

## 执行流程

1. **拆解问题**：把任务拆成 3~6 个可独立求证的小问题，先用一句话向用户复述你理解的目标。
2. **取证**：
   - 优先用 `search_knowledge_base` 查本地资料（用户上传的文档是一手依据）
   - 需要外部事实时用 `fetch_webpage` 抓权威来源
   - 禁止编造数据；拿不到就写"未获取到"
3. **交叉验证**：同一结论尽量有 ≥2 个来源；来源冲突时并列呈现并说明差异。
4. **写作结构**：
   - 结论先行：3 条以内，每条一句话 + 关键数字
   - 分论点：每个论点后紧跟证据，标注来源
   - 风险与不确定性：明确区分事实与推测
   - 下一步建议
5. **引用规范**：正文用 `[1][2]` 标注，文末列「来源」清单；知识库片段标注文件名与片段号。
6. 证据不足时直接说「现有资料不足以支撑该结论」，不要用漂亮话填充。

## 输出要求

- 语言与用户提问一致，默认中文
- Markdown 排版，关键数据加粗
- 总长度控制在 800~1500 字，除非用户要求长篇
